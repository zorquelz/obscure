# Scripts Directory

Utility scripts for building, testing, checking out, and packaging Obscure.

## Planned Scripts
- `apply_patches.sh` — Applies all patches in `patches/` to `~/Obscure/chromium/src`.
- `build_obscure.sh` — Invokes `autoninja` with standard Obscure flags.
- `export_patches.sh` — Exports diffs from the local branch to the patches directory.
