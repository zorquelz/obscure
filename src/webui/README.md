# Obscure WebUI Sources

This directory contains frontend source code for custom Obscure browser pages:
- `newtab/` — Launchpad and Project Spaces cockpit (`chrome://obscure-newtab`)
- `settings/` — Clean, transparent settings page (`chrome://obscure-settings`)
- `drawer/` — Lightweight security and port inspection drawer

These files are built using vanilla HTML/CSS/JS (or TypeScript) and served via Chromium's native WebUI data source.
